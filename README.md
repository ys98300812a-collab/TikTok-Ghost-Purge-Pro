# 🧹 TikTok Ghost Purge Pro (v3.1 Stable)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/Version-1.3.0-blue.svg)]()
[![Platform](https://img.shields.io/badge/Platform-Chrome-orange.svg)]()

這是一款專為 TikTok 創作者設計的「深度清理工具」，旨在自動識別並取消關注那些已被封號、註銷或長期不活躍的「幽靈帳號」，幫助提升帳號權重與互動率。

This is a deep cleaning tool designed for TikTok creators to automatically identify and unfollow banned, deactivated, or inactive "ghost accounts," helping to improve account authority and engagement rates.

---

## 🚀 實測證明：支援 10,000 關注量大戶 (Battle-Tested)

本工具由開發者親自實測，針對高關注數帳號具備極高穩定性：
* **實測數據**：成功將關注人數從 **9,989 人** 清理至 **9,875 人** 。
* **效能表現**：即便在萬人名單的載入壓力下，依然能維持精準判定。
* **突破限制**：實測證明，搭配「起始序號」功能，可完美克服 TikTok 的 429 流量限制。

**Battle-Tested**: Successfully verified with **10,000+** following lists. Stable performance confirmed during a real-world reduction from **9,989** to **9,875** followers.

---

## ✨ 核心功能 (Key Features)

* **🚀 斷點續傳 (Skip Count)**：支援設定起始序號，萬人名單即便中斷也能隨時接續，不必從頭開始。
* **🎯 精準判定邏輯**：嚴格鎖定「顯示名稱」，僅針對 `user+數字` 或官方封號關鍵字進行清理。
* **🎨 視覺化監控**：網頁即時標註狀態（綠色：正常、紅色：異常、透明：已跳過），進度一目了然。
* **🛡️ 模擬真人操作**：內建隨機 3-5 秒延遲與跳級機制，大幅降低觸發 TikTok 429 限制的風險。

## 🛠️ 安裝教學 (Installation)

1.  **下載本專案 (Download)**：點擊 `Code` -> `Download ZIP` 並解壓縮。
2.  **開啟擴充功能 (Extensions)**：在 Chrome 網址列輸入 `chrome://extensions/`。
3.  **載入專案 (Load)**：開啟「開發者模式」，點擊「載入解壓縮擴充功能」，選擇本專案資料夾。

---

## 📖 使用手冊 (Usage)

1.  開啟 TikTok 網頁並進入「關注中 (Following)」名單。
2.  點擊瀏覽器工具列的 **🧹 封號清理器 3.0**。
3.  **重要：** 若曾執行過，請在「起始序號」填入上次中斷的數字（例如 1390）。
4.  點擊「開始執行」，建議保持視窗開啟以維持腳本運行。
