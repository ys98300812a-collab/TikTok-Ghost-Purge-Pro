這是一款專為 TikTok 創作者設計的「深度清理工具」，旨在自動識別並取消關注那些已被封號、註銷或長期不活躍的「幽靈帳號」，幫助提升帳號權重與互動率。

## ✨ 為什麼選擇此工具？

市面上多數清理工具容易導致連線中斷或誤刪好友，本工具具備以下獨家技術：

* **🚀 斷點續傳 (Skip Count)**：支援設定起始序號，萬人名單即便中斷也能隨時接續，不必從頭開始。
* **🎯 精準判定邏輯**：嚴格鎖定「顯示名稱」，僅針對 `user+數字` 或官方封號關鍵字進行清理，絕不誤刪已改名的真實好友。
* **🎨 視覺化監控**：網頁即時標註狀態（綠色：正常、紅色：異常、透明：已跳過），進度一目了然。
* **🛡️ 模擬真人操作**：內建隨機 3-5 秒延遲機制，大幅降低觸發 TikTok 流量限制 (429 Error) 的風險。

## 📸 運作畫面
*(建議在此處上傳你的紅綠標籤截圖)*
* **綠色邊框**：判定為正常活粉。
* **紅色背景**：判定為廢號，執行退追。
* **透明度 0.3**：之前已處理過的區域。

## 🛠️ 安裝教學

1.  **下載本專案**：點擊右上角 `Code` -> `Download ZIP` 並解壓縮。
2.  **開啟擴充功能頁面**：在 Chrome 網址列輸入 `chrome://extensions/`。
3.  **開啟開發者模式**：切換右上角「開發者模式」開關。
4.  **載入專案**：點擊「載入解壓縮擴充功能」，選擇本專案資料夾。

## 📖 使用手冊

1.  開啟 TikTok 網頁並登入個人主頁。
2.  點開「關注中 (Following)」名單。
3.  點擊瀏覽器工具列的 **🧹 封號清理器 3.0**。
4.  **重要：** 若你曾執行過，請在「起始序號」填入上次中斷的數字（例如 6000）。
5.  點擊「開始執行」，建議保持視窗開啟以維持腳本運行。
